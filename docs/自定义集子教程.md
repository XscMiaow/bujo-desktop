# 自定义集子教程——在 journals/ 下建自己的收藏夹

日记目录里除了「年 → 月」的固定结构，还支持**自定义集子**：在 `journals/` 下
自己建一个**名字不是四位年份**的文件夹（比如 `读书笔记/`），它就会成为侧边栏里
一个独立的分组。

```text
journals/
  2026/                            ← 固定结构：年文件夹（不受影响）
    未来记录.md
    2026-10/
      月度记录.md
      2026-10-14.md
  读书笔记/                         ← 自定义集子（顶层、不叫年份即可）
    读书笔记.md
    深入理解ES6.md
  健身/                            ← 第二个集子也行
    danger-zone.md
```

## 一、怎么建

1. 在**日记目录**（默认项目根下的 `journals/`，可用 `BUJO_JOURNALS` 环境变量改到别处）下新建一个文件夹；
2. 文件夹名**不要是四位年份**（`2000`-`2099` 那种会被认成年文件夹），其余随意（中文也可以）；
3. 里面放 `.md` / `.markdown` 笔记，重启应用（或点侧边栏「↻ 刷新」）即可看到一栏「集子」分组。

- 分组内**文件按修改时间新→旧**排序；集子里再嵌套子文件夹也照常列出（都归属同一个集子）。
- 多个集子按文件夹名排序，紧跟在年份分组之后。
- 集子里的文件可以打开、被 AI 写入、被手工改标记——与应用打开其它日记完全一致。
- 已经打开的集子文件在侧边栏会高亮（跟其它日记一样）。

## 二、什么时候想用集子

- **不受时间维度约束的主题收藏**：读书笔记、健身计划、菜谱、会议模板…… 这些跟「某年某月」无关。
- **项目文集**：一个项目一口气几十页，想独立于每日记录滚动查看。
- **来自他人的参照**：把别人发的一包 `.md` 放进一个集子文件夹，跟自己的日记隔开。

## 三、规则与边界

- 只有**顶层的非年份文件夹**算集子；`journals/2026/2026-10/` 这类年/月内部结构不受影响。
- 根目录散落的裸 `.md`（旧版平铺残留）仍进「其他」分组，不按集子算。
- 隐藏文件夹（`.` 开头）、`README.md` 与非 Markdown 文件永远不进侧边栏。
- 集子文件夹的名字就是分组名；改名后刷新即可（文件路径变了侧边栏按新路径显示）。
- 删除集子文件夹里的文件后点「↻」或重启，分组随内容自动消失（空集子不显示）。
- 当前继续使用旧的**根级平铺日记**习惯也不受影响——集子是**增量功能**，不改变现有目录。

## 四、跟迁移/推迟、AI 聊天的交界

- 迁移目标只认「明天 / 下个月 / 未来记录」这三类固定结构，**不支持把条目迁移到自定义集子里**；
  想挪件任务去集子里，直接打开那篇集子文件把行复制过去即可。
- AI 聊天的写入目标依旧只有「当前笔记 / 今天的日记」——打开一篇集子里的文件当作「当前笔记」就能写进去。
