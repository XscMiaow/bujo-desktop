# 日记目录

这里存放按「子弹笔记」规则记录的日记，按 **年 → 月** 两级文件夹组织，每日记录一天一篇：

```text
journals/
  .journal-structure-v2        旧结构一次性迁移的标记（迁移只跑一次）
  2026/                        年文件夹
    未来记录.md                 年度（未来）记录，一年一篇
    2026-10/                   月文件夹
      月度记录.md               月度记录，一月一篇
      2026-10-07.md            每日记录，一天一篇
      2026-10-13.md
```

## 文件与文件夹命名约定

| 位置 | 命名 | 用途 |
| --- | --- | --- |
| `2026/` | 四位年份 | 年文件夹，收纳这一年的未来记录与各月文件夹 |
| `2026/未来记录.md` | 固定名 | 年度（未来）记录：体检、出差、纪念日等待安排事项，一年一篇 |
| `2026/2026-10/` | `YYYY-MM` | 月文件夹，收纳当月的月度记录与每日记录 |
| `2026/2026-10/月度记录.md` | 固定名 | 月度记录（本月目标与回顾），一月一篇 |
| `2026/2026-10/2026-10-07.md` | `YYYY-MM-DD` | 每日记录（当天随手记的子弹），一天一篇 |

每日记录命名统一用 `YYYY-MM-DD`，好处是文件名排序即时间顺序，方便以后做「昨天的任务迁移到今天」这类功能。

- 「未来记录」「月度记录」由应用在侧边栏点开对应节点时按模板创建（不存在才建，绝不覆盖）；
  每日记录在记入日记时自动建（迁移/推迟时，目标天/月/年的文件也按同一规则自动建）。
- 旧版平铺结构（`journals/2026-10-07.md`、`journals/2026-10.md`）会在应用启动时
  一次性自动迁进对应 年/月 文件夹，迁移完写入 `.journal-structure-v2` 标记，不再重复；
  目标文件已存在时不移动、不覆盖。

## 迁移与推迟写进来的行

界面上的 `»` 菜单和 CLI 的 `move` 命令会把一条搬去别的日志，规矩和子弹笔记的手工迁移一样：

| 去向 | 落在哪篇 | 新行写成 | 源文件里那行变成 |
| --- | --- | --- | --- |
| 推迟到明天 | 明天的每日记录 | 原文不变 | `- [<]`（计划） |
| 迁移到下个月 | 下个月的「月度记录」 | 原文不变 | `- [>]`（迁移） |
| 迁移到未来记录 | 某年的「未来记录」 | 原文不变 | `- [>]` |

- 新行按原来的类型落到对应文件里的小节（「## 任务 / ## 事件 / ## 笔记」），目标里已有同一句就不重复写。
- 源文件里只改标记、不删行。
- 已标 `[>]` 的不能从原地再迁一次：先「取消迁移」（在应用里点按钮，或 CLI
  `mark <file> <正文> --mark task`）恢复为待办，再迁；或者直接迁目标日志里的那份副本——
  两条路都等于重新迁移旧项目，且目标不会重复加。
- 跨月、跨年都会自动归位：例如把 12-31 推到明天，就是下一年的年文件夹里 `YYYY-01/` 月文件夹下的
  第一篇每日记录（`YYYY-01-01.md`）；迁移到「下个月」则落在下一年 1 月的「月度记录」。

## 每日记录模板

```markdown
# 2026-10-07 星期二

## 任务

- [ ] 待办任务
- [!] 优先任务
- [x] 已完成任务

## 事件

o 14:00 团队周会

## 笔记

- 随手记一条
```

## 月度记录与未来记录模板

由应用自动生成，形如：

```markdown
# 2026 年 10 月 · 月度记录

## 任务

## 笔记
```

```markdown
# 2026 年 · 未来记录

## 任务

## 笔记
```

## 侧边栏怎么用

应用左侧的日记栏按 **年 → 月** 分组：每个年份组带一行「未来记录」，每个月组带「月度记录」
和当月的每日记录，新的排在最上面；**双击打开**（单击只是选中，回车也能打开）。

- 只列 `.md` / `.markdown` 文本文件，非 Markdown 文件、本 `README.md` 与隐藏文件不会显示。
- 年度/月度记录还没建时，在列表里是一行「＋ 未来记录 / ＋ 月度记录」，双击即新建。
- 目录本身可以用 `BUJO_JOURNALS` 环境变量指到任意位置。

## AI 聊天写进来的内容

聊天面板的「写入笔记」选「今天的日记」时，内容会追加到当天文件（`2026/2026-10/2026-10-13.md`）末尾，形如：

```markdown
**AI 记录 · 14:32**

> 问：帮我列出今天的重点

- [ ] 先写周报
- 再整理一下收件箱
```

回答里的 `- [ ]` 会被识别成真任务，所以顶部统计和进度条会把它们算进去。

## 文件从哪来

应用第一步只读不写：用顶部「打开 .md 文件」、`Ctrl/Cmd + O`，或把文件拖进窗口即可查看本目录下的任何日记。
外部编辑器也可以直接改这些文件——应用重新载入就能看到；启动时会自动把旧版平铺日记迁到 年/月 文件夹。
