# 日记目录

这里存放按「子弹笔记」规则记录的日记，一天一个 Markdown 文件，直接放在本目录下（不再分子目录）。

## 文件命名约定

| 文件 | 用途 |
| --- | --- |
| `2026-10-07.md` | 每日日志（当天随手记的子弹） |
| `2026-10.md` | 月度日志（本月目标与回顾） |
| `future-log.md` | 未来日志（体检、出差、纪念日等待安排事项） |

命名统一用 `YYYY-MM-DD`，好处是文件名排序即时间顺序，方便以后做「昨天的任务迁移到今天」这类功能。

## 每日日志模板

```markdown
# 2026-10-07 星期二

## 任务

- [ ] 待办任务
- [!] 优先任务
- [x] 已完成任务

## 事件

o 14:00 团队周会

## 笔记

- 随手记一句
```

## 书写规则

- `- [ ]` 任务、`- [x]` 完成、`- [>]` 迁移、`- [<]` 计划、`- [!]` 优先、`-` 笔记、`o` 事件。
- 两个空格或制表符缩进表示子条目。
- 每月回顾时把未完成的任务用 `[>]` 迁到未来的日志文件里。

## 左侧日记栏

应用左侧会列出本目录里的所有 Markdown 文件，最新的排在最上面：**双击打开**（单击只是选中，回车也能打开）。

- 只列一层文件，子目录里的内容不会显示。
- 本 `README.md` 是说明文档，不会被当成日记列进去。
- 目录本身可以用 `BUJO_JOURNALS` 环境变量指到任意位置。

## AI 聊天写进来的内容

聊天面板的「写入笔记」选「今天的日记」时，内容会追加到当天文件的「## 笔记」下面，形如：

```markdown
**AI 记录 · 14:32**

> 问：帮我列出今天的重点

- [ ] 先写周报
- 再整理一下收件箱
```

回答里的 `- [ ]` 会被识别成真任务，所以顶部统计和进度条会把它们算进去。

## 文件从哪来

应用第一步只读不写：用顶部「打开 .md 文件」、`Ctrl/Cmd + O`，或把文件拖进窗口即可查看本目录下的任何日记。
之后添加编辑功能时，新笔记也默认写进这个目录。
