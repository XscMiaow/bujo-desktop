# 子弹笔记 · Bullet Journal Desktop

基于 Electron 的子弹笔记（Bullet Journal）桌面应用。

当前进度：**主窗口 + 左侧日记栏 + 读取并显示 .md 笔记 + AI 聊天写入笔记**。
直接在窗口里手写/编辑条目是下一步，数据格式已经按子弹笔记语法打好基础（见下文）。

## 运行

```bash
npm install
npm start          # 启动应用
npm test           # 单元测试（解析器 + 文件读取 + 日记目录扫描）

# 端到端自检：preload → IPC → 解析 → 渲染 → 日记栏双击切换 → 折叠，并输出截图
npm run smoke
npm run smoke -- journals/2026-10-07.md   # 也可以指定自检打开的文件
```

也可以直接把 `.md` 文件拖进窗口，或用 `npm start -- journals/2026-10-07.md` 启动时直接打开。

## AI 聊天（与笔记打通）

右侧面板可以和模型聊天，回答能一键写进笔记：

- 点工具栏的「AI 聊天」（或 `Ctrl/Cmd + J`）展开右侧面板，聊天内容流式显示。
- 每条回答下面有「写入笔记」：按当前「记入」选择的目标，写进**当前打开的笔记**或**今天的日记**
  （今天的日志不存在时会按模板新建 `journals/YYYY-MM-DD.md`）。
- 写入时会把回答改写成子弹笔记条目：`- [ ]` 之类的任务原样保留，`*` / `1.` / `>` 等写法统一成 `-`,
  代码块和标题原样保留，并在前面加上一行 `**AI 记录 · 14:32**` 和你的问题。
- 生成过程中可以「停止」；没配密钥时会直接提示去设置。

### 设置与密钥

点 `⚙` 打开设置，选服务商预设（OpenAI / DeepSeek / Moonshot / 智谱 / OpenRouter / 本地 Ollama / 自定义）
再填 API Key。接口是 OpenAI 兼容的 `/chat/completions`，所以任何兼容服务填上地址和模型名都能用。

密钥的安全边界：

- 密钥只存在**主进程**，用 Electron `safeStorage`（Windows DPAPI / macOS 钥匙串）加密后写在
  `app.getPath('userData')/settings.json`——不进项目目录、不进版本库，也不出现在界面、日志或截图里。
- 渲染层调 `settings:get` 只能拿到「是否已配置」和末四位提示；**明文绝不会下发到界面**。
- 系统不支持加密时会降级为明文存储，并在设置里如实提醒。
- 聊天请求也全部在主进程发出，界面只接收流式文本。
- 「写入笔记」有白名单：只能写你本次打开过的文件，或日记目录里的文件，其它路径一律拒绝。

## 主窗口能做什么

- **左侧日记栏**：列出日记目录（默认 `journals/`）里所有 Markdown 文件，最新在前；**单击选中、双击打开**，回车也能打开；当前打开的一篇会高亮。
- **可收起**：点标题栏的 `‹` / `›` 把日记栏收成一条 42px 的窄条，收起后只留「展开」按钮（列表、目录路径、刷新按钮都隐藏），状态会记住。
- **打开笔记**：顶部按钮、`Ctrl/Cmd + O`、拖拽 `.md` 到窗口，或通过启动参数传入路径。
- **预览 / 原文切换**：预览用 Markdown 渲染，子弹条目按类型着色；原文显示文件原始内容。
- **重新载入**：在外部编辑器改完文件后一键刷新。
- **统计条**：待办 / 完成 / 优先 / 事件 / 迁移 / 笔记数量与完成进度。
- 笔记中的 http(s) 链接交给系统浏览器打开，不会在应用内跳转。

除了 AI 的「写入笔记」（只会追加到白名单内的文件），其余操作都只读，不会改写你的笔记。

## 子弹笔记语法

一行是不是「子弹」，以及属于哪种子弹，由行首符号决定：

| 写法 | 显示符号 | 含义 |
| --- | --- | --- |
| `- [ ] 任务` / `• 任务` | `•` | 待办任务 |
| `- [x] 任务` | `✕` | 已完成（带删除线） |
| `- [>] 任务` | `›` | 迁移到未来日志 |
| `- [<] 任务` | `‹` | 计划 / 安排到某天 |
| `- [!] 任务` | `★` | 优先任务 |
| `- 一句话` | `–` | 普通笔记 |
| `o 事件` | `o` | 事件（只记录，不行动） |

其他规则：

- 用两个空格或制表符缩进即可形成子条目层级。
- 代码围栏（` ``` `）里的内容和普通段落不会被当成子弹。
- 复选框之外的 Markdown（标题、表格、引用、代码块）仍按标准 Markdown 渲染。

## 项目结构

```
src/
  main/
    main.js           主进程：创建主窗口、注册 IPC、菜单/链接安全策略
    file-service.js   只读的 Markdown 文件读取与校验
    journal-service.js 日记目录扫描 + 按模板新建当天的日志
    note-service.js   追加写入笔记（保证空行与结尾换行，不改动原有内容）
    settings-service.js 设置与 API Key（safeStorage 加密，密钥不外泄）
    chat-service.js   OpenAI 兼容的流式聊天（SSE 解析、超时、取消、错误翻译）
  preload/
    preload.js        contextBridge 白名单，渲染层唯一的文件访问入口
  renderer/
    index.html        主窗口结构
    styles.css        深色主题与子弹符号配色
    renderer.js       打开/拖拽文件、解析结果渲染、视图切换、日记栏与折叠
    chat.js           聊天面板、设置弹窗、写入笔记、流式增量渲染
  shared/
    bullet-parser.js  子弹笔记解析器（浏览器与 Node 共用，含单元测试）
    chat-to-note.js   AI 回答 → 子弹笔记条目
    journal-date.js   日期/星期/时间标签（主进程与渲染层共用）
samples/
  Bullet-Journal.md   示例笔记（用于演示各种子弹符号）
journals/             日记目录：一天一个 .md 文件，命名约定见 journals/README.md
test/                  node:test 单元测试
```

日记目录可用环境变量 `BUJO_JOURNALS` 指定（默认是项目根下的 `journals/`）：

```bash
BUJO_JOURNALS=D:/我的日记 npm start
```

安全模型：渲染层 `contextIsolation: true` + `nodeIntegration: false`，只有
`preload.js` 暴露的 `window.bujo`（读文件、列目录、选文件、打开外链）可用，并有 CSP 限制。
日记栏只能看到日记目录里的一层 `.md` 文件，读不了目录以外的东西。

自检会启动一个隐藏窗口完成全部验证，验证不通过时退出码非 0，成功时输出三张截图：
`screenshots/main-window.png`（展开）、`sidebar-collapsed.png`（收起）、`chat-panel.png`（聊天与写入笔记）。

自检覆盖的内容：解析与渲染、日记栏双击切换、折叠（含计算样式与像素宽度）、
以及**聊天全链路**——它会起一个本地假模型服务（不联网、不用真密钥），把设置指向它，
跑完「发消息 → 流式接收 → 写入笔记 → 文件内容校验」，并数一遍右侧面板的像素确认真的画出了内容，
最后把原来的设置文件恢复回去。
